# Evermore Pictures — Luxury Wedding Cinematography & Post-Production Editing

A luxury, cinematic, and high-converting website built for **Evermore Pictures**, tailored specifically for wedding cinematography, editorial photography, and dedicated post-production / video editing services.

---

## 🌟 Highlights & Features

- **Luxury Cinematic Aesthetic**: Deep Obsidian Noir (`#0a0a0c`) paired with Champagne Gold accents and editorial serif typography.
- **Dual-Focused Offering**:
  - **For Couples**: Full-day 4K multi-camera wedding films, aerial drone cinematography, and candid fine-art photography.
  - **For Creators & Studios**: High-end post-production editing suite, DaVinci Resolve color grading, dialogue isolation, and licensed scoring.
- **Interactive Before & After Color Grading Slider**: Smooth mouse & touch draggable comparison slider demonstrating RAW Flat Log vs. Evermore's signature warm cinematic grade.
- **Featured Films Showcase**: Playable cinematic video modal for wedding films.
- **Filterable Portfolio**: Real-time filtering across Films, Photography, Color Grading, and Pre-Wedding categories with full-screen Lightbox.
- **Investment & Pricing Matrix**: 3 clear tiers (*Timeless Story*, *The Cinema Luxe*, and *The Editor's Suite*).
- **Interactive Booking Form with WhatsApp Quick Connect**: Generates a pre-filled, organized WhatsApp inquiry directly to your phone number, plus instant on-screen toast feedback.
- **Zero-Dependency Architecture**: Pure HTML5, CSS3, Tailwind CSS CDN, and vanilla ES6 JavaScript. No build step, no npm install required, blazingly fast.

## 🚀 How to Preview Locally

### Option 1: Double-Click the Launcher
Simply double-click:
```
preview.bat
```
This automatically starts the local server and opens `http://localhost:3000` in your default browser.

### Option 2: Using the Command Line
Run with the Antigravity bundled Node runtime:
```powershell
& "C:\Users\Students\AppData\Roaming\Antigravity\bin\agy-node.cmd" serve.js
```
Then visit [http://localhost:3000](http://localhost:3000).

## 🌐 How to Publish to the Web (100% Free)

You can publish this website live on the internet with a public link in less than a minute:

### Method 1: Netlify Drop (Fastest — 15 Seconds, No Terminal Needed)
1. Go to **[https://app.netlify.com/drop](https://app.netlify.com/drop)** in your web browser.
2. Drag and drop the `evermore-pictures` folder directly onto the upload area on Netlify.
3. Netlify will immediately publish your website and give you a free, live HTTPS link (e.g., `https://evermore-pictures.netlify.app`) with custom domain support!

### Method 2: Vercel
1. Go to **[https://vercel.com](https://vercel.com)**.
2. Sign in or sign up for free.
3. Drag and drop the `evermore-pictures` folder or link via GitHub.
4. Click **Deploy** to receive an instant live URL.

### Method 3: GitHub Pages
1. Create a repository named `evermore-pictures` on GitHub.
2. Upload the files (`index.html`, `css/`, `js/`, `README.md`).
3. Go to **Repository Settings** > **Pages** > Select branch `main` and save.
4. Your site will be live at `https://<username>.github.io/evermore-pictures/`.

## ⚙️ How to Personalize Your Details

1. **Update WhatsApp Number**:
   - In `index.html` line 462 and in `js/main.js` line 247, change `919876543210` to your actual WhatsApp phone number (with country code, no `+` or spaces).
2. **Update Contact Email & Coordinates**:
   - In `index.html` footer, edit `hello@evermorepictures.com` and phone details.
3. **Change Video Samples**:
   - In `index.html` under the `#films` section, update the `data-video-url` attributes with your own YouTube or Vimeo embeds.
